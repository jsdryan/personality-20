# 人格二十題

二十個生活情境的人格測驗。憑直覺判斷「像不像我」，算出五大人格特質（Big Five）分數，並對照出 MBTI 風格的四個字母。

網址：https://jsdryan.github.io/personality-20/

## 功能

- **結果頁**：四字母類型與次接近的類型、每個字母的把握程度、五項特質分數條、該類型的簡介與常見誤會、答案裡的內在拉扯。
- **中線追問**：分數落在 40% 到 60% 的特質，可多答 3 題追問，把中線分出方向。
- **結果連結**：答案編碼在網址裡（`#a=…&n=名字`），對方打開就看到結果，不需要後端。
- **兩人比較**：打開或貼上對方的結果連結，顯示兩人的分數對照、相同與不同的字母、差最多的一項，以及不同字母的相處提示。
- **猜猜對方**：替對方作答一次，把猜測連結（`#g=…`）傳給對方，或拿到對方結果後看猜中幾題、哪些題看走眼。
- **結果圖卡**：用 Canvas 產生一張可存圖分享的結果卡。
- **歷次紀錄**：每次完成自動記一筆，顯示與上一次的分數差。
- **其他**：題目隨機順序、深淺色切換、中英文切換。

## 技術

- 純靜態單頁，沒有後端。作答進度、結果、歷次紀錄與匯入的對方結果都只存在瀏覽器的 localStorage。
- 計分：完全不像我 1 分到非常像我 4 分，反向題以 5 減去原始分數；每項特質 4 題，百分比 = (總分 − 4) ÷ 12。
- 字母對照：外向性高為 E 低為 I，開放性高為 N 低為 S，親和性高為 F 低為 T，盡責性高為 J 低為 P，情緒起伏高為 -T 低為 -A。
